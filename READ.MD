# Python Calculator

A simple Python-based calculator made for my Python Programming Lab project.

The calculator can perform basic calculations, advanced mathematical operations, evaluate expressions, and store calculation history.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Floor Division
- Power
- Square Root
- Absolute Value
- Factorial
- Percentage Calculation
- Mathematical Expression Evaluation
- Calculation History
- JSON-based history storage
- Input validation
- Error handling
- Multiple calculations in one session
- Automated testing
